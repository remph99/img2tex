Img2Tex @VERSION@ — 本地公式识别

适用环境：Windows x64。当前发行版在 Windows 11 验证；Windows 10 22H2 的跨机兼容性尚需更多实测。
程序已包含 Python、Qt、PyTorch、字体、转换器和 Xiaomi-OCR-0 模型，无需安装 Python 或 conda。
识别、预览和导出均可离线完成。CPU 模式始终可选；CUDA 模式需要兼容的 NVIDIA 显卡驱动。

安装版：运行 Setup.exe，按向导安装。可创建开始菜单及桌面快捷方式。
配置、历史、日志和应用缓存保存在当前用户的 LocalAppData\Img2Tex。
覆盖安装会保留这些用户数据，卸载默认也不删除它们。

便携版：完整解压 ZIP 后，双击 Img2Tex.exe。必须保留 _internal、models 和 portable.flag。
配置、历史、日志和应用缓存位于程序旁的 data 目录。移动整个文件夹即可携带数据与随包模型。
请放在可写的磁盘或移动硬盘中；只读目录无法保存历史，将显示错误，不会偷偷切换数据目录。
若手动选择了文件夹外的其他模型，该模型路径仍依赖外部位置；随包模型则使用相对路径。
关闭程序后再移动、备份或删除 data，避免 SQLite 正在写入。

使用：
1. 选择 CPU 或 CUDA。初始默认 CPU。
2. 自行截图或复制图片，在窗口内按 Ctrl+V，或点击“粘贴图片”。模型会按需加载并自动识别。
3. 连续粘贴只识别最新图片；取消和历史恢复会清除等待中的识别请求。
4. LaTeX 源码可编辑，模型原始输出单独保留。等待加载/识别期间的手动编辑不会被覆盖。
5. “复制 LaTeX”右侧箭头可选择并记住无附加、$…$、$$…$$、\(…\)、\[…\]、equation 格式。
6. “复制 MathML(Word)”可供 MathType/Word 导入；DOCX 导出含可编辑 OMML。PNG/SVG 是渲染图像。
7. 复制按钮的其他菜单中可导出 AsciiMath、Typst、PNG、SVG、DOCX。不支持的结构会明确提示。
8. 导入/拖入文件后仍可点击“开始识别”，也可以用该按钮重新识别。Ctrl+C 保持正常复制文本。

识别结果需要核对。当前不包含 PDF 整页解析、批量识别、云账号或自动更新。
缺少可选加速内核的日志提示不代表推理失败，当前使用可工作的 PyTorch 参考实现。
若需要诊断，查看数据目录中的 logs；不要将包含个人公式图片或历史的 data 目录一起发行。

发行文件没有代码签名证书。请核对随发行提供的 SHA256SUMS.txt；校验和用于检查文件完整性。
第三方组件许可及源码入口见 THIRD_PARTY_NOTICES.txt 和 _internal 中相应包的许可证。
