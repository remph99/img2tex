Img2Tex @VERSION@ — 本地公式识别

适用环境：Windows x64，推荐 Windows 11。Windows 10 22H2 尚待跨机验收。
完整包已包含 Python、Qt、PyTorch、公式渲染资源及 Xiaomi-OCR-0 权重，无需安装 Python 或 conda。
完整版支持 CPU/CUDA；文件名带 -cpuonly 的版本仅支持 CPU，两版均可离线识别。
完整版 CUDA 需要 Turing（计算能力 7.5）或更新的 NVIDIA GPU，以及支持 CUDA 13 的 R580 或更新驱动。
无需另装 CUDA Toolkit/cuDNN。驱动缺失或不兼容时会提示原因并使用 CPU。
以上是兼容要求，不代表每款显卡和驱动均已实测。AMD/Intel 显卡使用 CPU。
建议内存 16 GB，CUDA 显存 6 GB 以上、8 GB 更宽裕；低配置边界尚待实测。

便携版：完整解压 ZIP 后双击 Img2Tex.exe。保留 _internal、models、img2tex-runtime.json 和 portable.flag。
设置、历史、日志与缓存保存在程序旁的 data 目录。退出后移动整个目录即可携带模型及历史。
请放在可写磁盘；路径不可写时明确报错，不会切换用户数据目录。
安装版（若提供）：用户数据保存在 LocalAppData\Img2Tex，覆盖安装和卸载默认保留用户数据。

使用：
1. 启动后后台自动检测设备、加载模型并预热，状态栏显示进度。窗口保持可操作。
2. 自行复制/截图，在应用内 Ctrl+V 或点击“粘贴图片”。准备期间只保留最新图片，模型就绪后自动识别。
3. “导入图片、粘贴图片、开始识别、取消”在顶部保留。导入/拖入文件后点击“开始识别”。
4. 菜单“设置 → 计算设备”选择 CPU/CUDA；识别期间不能切换。CPU Only 版只提供 CPU。
5. 模型目录自动定位，不必手动选择。初始化失败可在“设置 → 重新初始化模型”重试。
6. 缺少模型时请完整解压并校验发行包；不会自动联网下载。模型权重约 1.75 GB。
7. LaTeX 可编辑，模型原始输出单独保留。等待或识别期间的手动编辑不会被覆盖。
8. 保留三个复制按钮与六种 LaTeX 外层格式；文件菜单可导出 PNG、SVG、可编辑 DOCX。
9. 菜单“视图”控制本地历史，“帮助 → 关于 Img2Tex”显示版本和发行类型。

启动预热会持续占用内存/显存；不同大小图片仍可能有额外初始化开销。
识别结果需要核对。缺少可选加速内核的日志提示不代表推理失败。
诊断日志在 data\logs；不要将含个人图片或公式的 data 目录一起发行。
发行文件未签名，请核对 SHA256SUMS.txt。第三方许可见 THIRD_PARTY_NOTICES.txt。
