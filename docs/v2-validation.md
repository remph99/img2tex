# Img2Tex 2.0.0 验收记录

日期：2026-11-02 至 2026-11-03（Asia/Shanghai）。本机 Windows 11 x64，Ryzen 9 7900X、64 GB 内存、RTX 4070 Ti SUPER 16 GB。CPU/GPU 最低配置和干净机器兼容边界不由本机结果推定。

## 实现范围

- 版本统一为 2.0.0；完整版与 -cpuonly 便携包使用同一套源码、相同固定权重和数据格式。
- 删除 Qt 调试资源和除中文/英文以外的语言资源；保留 WebEngine、转换符号表、许可证和动态依赖的 CUDA 库。
- 窗口显示后启动独立模型进程，自动检测、加载、短推理预热；就绪后复用。CPU-only 不检测/初始化 CUDA；完整版 CUDA 初始化失败明确提示并只回退一次 CPU。
- 菜单栏包含文件、视图、设置、帮助；保留导入图片、粘贴图片、开始识别、取消及复制按钮。
- 设备设置改为独立窗口，关于显示版本及发行类型。移除模型目录、手动加载及 GUI 下载控件/代码，保留 CLI 模型准备。
- 旧版有效自定义路径、相对模型路径、SQLite 历史和编辑内容保持兼容；路径失效时提示并尝试完整随包模型。

正式构建使用 `--clean` 清理本版 PyInstaller 缓存，避免增量 PYZ 保留清理前的字节码。构建后分别比较 engine、ui.main、__main__ 的完整代码对象与当前源码编译结果；CPU 版和重新构建的完整版均一致。

## 源码验证

完整回归 183 tests passed，9 subtests passed。新增覆盖：资源过滤和 CPU/CUDA 构建依赖检查、发行类型传递、CPU-only 避免 CUDA、旧 GPU 拒绝、GPU 预热失败只回退一次、设置应用幂等、菜单与关于、CPU-only 旧设置迁移、加载/预热期间排队识别与取消、失败后控件恢复、旧路径回退。原有图片处理、导出、编辑保护、迟到结果过滤、历史与便携迁移测试保留或迁移。

独立只读代码审查完成，无剩余可操作问题；发现的手动排队识别取消按钮问题及 CPU 安装包分卷命名问题已修复。发行成品的验收结论在下方完成后记录。

完整版 ZIP 减少约 30.80 MB（0.842%），解压内容减少约 132.71 MB；主要体积仍是 CUDA 运行库和模型。CPU-only ZIP 减少约 1.90 GB（52.014%）。这里 GB=10^9 字节，GiB=2^30 字节。

两版实际最终 ZIP 均通过 CRC、固定权重 SHA-256、空白发行数据目录、中文空格路径迁移、仅系统 PATH 与 HF_HUB_OFFLINE=1 的真实 EXE 识别。完整版分别通过隐藏 CUDA 的 CPU 模式和真实 CUDA 模式；CPU-only 检查确认没有 CUDA DLL，runtime 元数据 cuda_runtime=null。未禁用主机网络或声称无驱动机器通过。

## 验证边界

- 未在另一台干净 Windows、无 NVIDIA 驱动实体机或 Windows 10 上验收。
- 隐藏 CUDA 设备及精简 PATH 的本机检查不等同于上述环境。
- 预热将部分首次等待前移并持续占用内存/显存；不同图像尺寸仍可能初始化额外算子。
- 少量印刷公式样例只验证功能闭环，不代表大规模识别准确率或跨机器性能。
- 本地已生成两版离线便携 ZIP。根据 2026-11-03 的发布指令，GitHub v2.0.0 Release 仅发布 CPU-only ZIP 与其 SHA256SUMS.txt；完整版保留本地，原 v1.0.0 发行不变，不发布安装包。
